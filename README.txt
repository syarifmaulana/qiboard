MyBoard - keyboard + clipboard otomatis ke Inbox.md

1. Buat repo baru di github.com, upload SEMUA isi folder ini (termasuk folder .github).
2. Tab Actions > build-apk > tunggu sekitar 4 menit > unduh artifact "MyBoard-apk" (zip berisi app-debug.apk).
3. Install APK, buka MyBoard, tekan tombol 1, 2, 3.
   Tombol 3: pilih folder yang disinkronkan ke laptop (Syncthing / Obsidian / Drive).
   Setiap yang kamu copy akan ditambahkan ke Inbox.md di folder itu.
